# TRACE-RCA Basic Model Scope

## Current milestone

The first milestone uses a supervised multilayer perceptron to classify five simulated incident root causes from numerical telemetry.

## Current root-cause classes

1. CPU Saturation
2. Memory Leak
3. Database Connection Exhaustion
4. Network Latency
5. Service Crash

## Future extensions

- Temporal LSTM or GRU
- Log-text encoder trained from project data
- Service-topology graph neural network
- Multimodal fusion model
- FastAPI integration
